ScreenGadgetY()

Syntax

Result = ScreenGadgetY(#ScreenGadget)
Description
Returns the Y position of the specified gadget.

Parameters

#ScreenGadget The gadget to use.

Return value

The Y position, in pixels, of the specified gadget starting from the inside of the top edge of the gadget list that the gadget is in.

See Also

ScreenGadgetX()

Supported OS

All
