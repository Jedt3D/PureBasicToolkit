RemoveScreenGadgetItem()

Syntax

RemoveScreenGadgetItem(#ScreenGadget, Position)
Description
Removes an item of the specified #ScreenGadget at the given Position.

Parameters

#ScreenGadget The gadget to use.
Position The item position to remove. The first position index starts from zero.

Return value

None.

Remarks

Supported gadgets:

- ComboBoxScreenGadget()
- PanelScreenGadget()
- ListViewScreenGadget()

Supported OS

All
