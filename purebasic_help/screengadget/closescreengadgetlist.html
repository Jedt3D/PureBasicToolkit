CloseScreenGadgetList()

Syntax

CloseScreenGadgetList()
Description
Closes the current gadget list creation and go back to the previous GadgetList.

Parameters

None.

Return value

None.

Remarks

This function is supported by the following gadgets:

- ContainerScreenGadget()
- PanelScreenGadget()
- ScrollAreaScreenGadget()

Supported OS

All
