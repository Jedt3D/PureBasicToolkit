ButtonImageScreenGadget()

Syntax

Result = ButtonImageScreenGadget(#ScreenGadget, x, y, Width, Height, ImageID [, Flags])
Description
Creates a button with an image in the current GadgetList.

Parameters

#ScreenGadget The identification number of the new gadget. #PB_Any can be used to automatically generate this number.
x, y, Width, Height The position and dimensions of the new gadget.
ImageID The gadget image identification number. Use ImageID() to get this ID from an image.
Flags (optional) Not supported.

Return value

Returns a non-zero value on success, zero otherwise. If #PB_Any was used for the #ScreenGadget parameter, then the return value is the gadget ID number, generated automatically.

Supported OS

All
