RenderScreenGadgets()

Syntax

RenderScreenGadgets()
Description
Displays windows and gadgets on the screen.

Return value

None.

Remarks

This function must be placed in the rendering loop. The background needs to be "refreshed", for example with @clearscreenor @renderworld(3D).

Supported OS

All
