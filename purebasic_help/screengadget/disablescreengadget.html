DisableScreenGadget()

Syntax

DisableScreenGadget(#ScreenGadget, State)
Description
Disable or enable the gadget.

Parameters

#ScreenGadget The gadget to enable or disable.
State The new state of the gadget. If State = 1, the gadget will be disabled, if State = 0 it will be enabled.

Return value

None.

Supported OS

All
