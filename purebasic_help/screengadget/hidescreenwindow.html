HideScreenWindow()

Syntax

HideScreenWindow(#ScreenWindow, State)
Description
Hides or shows the specified #ScreenWindow.

Parameters

#ScreenWindow The window to use.
State It can take the following values: 
  #True : the #ScreenWindow is hidden
  #False: the #ScreenWindow is shown

Return value

None.

Supported OS

All
