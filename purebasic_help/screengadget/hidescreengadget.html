HideScreenGadget()

Syntax

HideScreenGadget(#ScreenGadget, State)
Description
Hide or show a gadget.

Parameters

#ScreenGadget The gadget to use.
State The new state of the gadget. If State = 1, the gadget will be hidden, if State = 0 it will be shown.

Return value

None.

See Also

DisableScreenGadget()

Supported OS

All
