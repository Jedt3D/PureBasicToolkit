ScreenGadgetHeight()

Syntax

Result = ScreenGadgetHeight(#ScreenGadget)
Description
Returns the height of the specified gadget.

Parameters

#ScreenGadget The gadget to use.

Return value

The height, in pixels, of the specified gadget.

See Also

ScreenGadgetWidth()

Supported OS

All

<- ScreenEventType() - ScreenGadget Index - ScreenGadgetID() ->
