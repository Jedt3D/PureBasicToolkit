ScreenGadgetType()

Syntax

Result = ScreenGadgetType(#ScreenGadget)
Description
Returns the type of gadget that is represented by the specified gadget. It can be useful to write generic functions that work with more than one type of gadget.

Parameters

#ScreenGadget The gadget to use.

Return value

It can be one of the following values: 
  #PB_ScreenGadgetType_Button        : ButtonScreenGadget()
  #PB_ScreenGadgetType_CheckBox      : CheckBoxScreenGadget()
  #PB_ScreenGadgetType_ComboBox      : ComboBoxScreenGadget()
  #PB_ScreenGadgetType_Container     : ContainerScreenGadget()
  #PB_ScreenGadgetType_Editor        : EditorScreenGadget()
  #PB_ScreenGadgetType_Image         : ImageScreenGadget()
  #PB_ScreenGadgetType_ListView      : ListViewScreenGadget()
  #PB_ScreenGadgetType_Option        : OptionScreenGadget()
  #PB_ScreenGadgetType_Panel         : PanelScreenGadget()
  #PB_ScreenGadgetType_ProgressBar   : ProgressBarScreenGadget()
  #PB_ScreenGadgetType_ScrollArea    : ScrollAreaScreenGadget()
  #PB_ScreenGadgetType_ScrollBar     : ScrollBarScreenGadget()
  #PB_ScreenGadgetType_String        : StringScreenGadget()
  #PB_ScreenGadgetType_Text          : TextScreenGadget()
  #PB_ScreenGadgetType_Unknown       : The type is unknown. Most likely it is not a PB gadget at all.

Supported OS

All
