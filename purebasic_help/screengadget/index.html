PureBasic - ScreenGadget

Overview

The ScreenGadget library allows you to create complex graphical user interfaces (GUIs) directly on the screen.
The syntax of this library is similar to the library Gadget.

InitScreenGadgets() must be called before being able to use the commands related to gadgets.
