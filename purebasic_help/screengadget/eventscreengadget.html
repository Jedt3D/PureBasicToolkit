EventScreenGadget()

Syntax

Result = EventScreenGadget()
Description
After an event of type #PB_Event_Gadget (returned by ScreenWindowEvent()), use this function to determine which gadget has been triggered.

Parameters

None.

Return value

The gadget number associated to the last #PB_Event_Gadget event.

See Also

ScreenWindowEvent()

Supported OS

All
