ResizeScreenWindow()

Syntax

ResizeScreenWindow(#ScreenWindow, x, y, Width, Height)
Description
Move and resize the given window to the given position and size.

Parameters

#ScreenWindow The window to resize.
x, y The new window position. If 'x' or 'y' is set to #PB_Ignore, the current value of 'x' or 'y' won't be changed.
Width, Height The new window size. If 'Width' or 'Height' is set to #PB_Ignore, the current value of 'Width' or 'Height' won't be changed.

Return value

None.

Supported OS

All
