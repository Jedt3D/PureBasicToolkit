CloseHID()

Syntax

CloseHID(#HID)
Description
Close the specified HID device.

Parameters

#HID The HID device to close.

Return value

None.

Remarks

Once the HID device is closed, it may not be used anymore. All resources associated with the device are released.

See Also

OpenHID(), OpenHIDPath()

Supported OS

All
