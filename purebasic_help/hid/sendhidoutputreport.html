SendHIDOutputReport()

Syntax

Result = SendHIDOutputReport(#HID, *Buffer, Size)
Description
Send an output report to the HID device. Output reports are used for host-to-device communication and include the report ID.

Parameters

#HID The HID device to send to.
*Buffer The buffer containing the report to send.
Size The size of the report.

Return value

Returns the number of bytes sent, or zero if there was an error.

See Also

ReceiveHIDInputReport(), WriteHIDData()

Supported OS

All
