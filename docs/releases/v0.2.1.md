## Suggested GitHub Release Notes

```md
## PureBasic Toolkit v0.2.1

The project now ships under the new **PureBasic Toolkit** name and reaches its first strong editor baseline for VS Code.

### Highlights

- PureBasic file recognition for `.pb`, `.pbi`, and `.pbp`
- donor-based syntax highlighting tuned against real PureBasic sources
- curated snippets and starter templates for console and window applications
- `PureBasic: Check Syntax Current File`
- `PureBasic: Compile Current File`
- `PureBasic: Run Current File`
- branded release assets including icon, banner, screenshots, and demo GIF

### Notes

- most example files in this repo are console programs
- when running those examples from the PureBasic IDE, set:
  - `Compiler`
  - `Compiler Options`
  - first tab: `Executable Format`
  - choose `Console`

### Packaging

- artifact: `purebasic-toolkit-0.2.1.vsix`
- license: MIT
```
