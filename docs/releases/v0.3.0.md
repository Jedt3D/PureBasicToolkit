## Suggested GitHub Release Notes

```md
## PureBasic Toolkit v0.3.0

This release starts the first Phase 3 slice for PureBasic Toolkit by adding packaged offline documentation and hover help on top of the existing editor workflow.

### Highlights

- `PureBasic: Open Documentation for Symbol`
- hover docs for recognized PureBasic commands and indexed help topics
- packaged local `purebasic_help` pages for offline documentation lookup
- existing syntax highlighting, snippets, and check/compile/run commands remain in place

### Notes

- most example files in this repo are console programs
- when running those examples from the PureBasic IDE, set:
  - `Compiler`
  - `Compiler Options`
  - first tab: `Executable Format`
  - choose `Console`

### Packaging

- artifact: `purebasic-toolkit-0.3.0.vsix`
- license: MIT
```
